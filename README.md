# Ready When You Are

初動時間(やろうと決めてから実際に手を動かすまでの時間)を測って記録するツール。

READY... を押した瞬間から計測が始まり、実際に着手できたら GO! を押す。その間隔が記録として残り、日ごとの平均が積み上がっていく。

## アップロードするファイル

リポジトリの一番上の階層に、次のファイルをすべて置く。

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `manifest.json` | ホーム画面に追加した時の名前とアイコンの設定 |
| `icon-192.png` / `icon-512.png` | Android・PC用のアイコン |
| `icon-180.png` | iPhone のホーム画面用アイコン |
| `icon-32.png` / `favicon.ico` | ブラウザのタブ用アイコン |
| `README.md` | この説明(任意) |

アイコンは肉球マーク。ファイル名を変えると読み込まれなくなるので、そのままにしておくこと。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る(名前は何でもよい。例:`ready-when-you-are`)
2. `index.html` をアップロードする
   - リポジトリ画面の **Add file** → **Upload files** から、ドラッグ&ドロップして **Commit changes**
3. **Settings** タブ → 左メニューの **Pages** を開く
4. **Source** で `Deploy from a branch` を選び、Branch を `main` / `/ (root)` にして **Save**
5. 1〜2分待つと、同じ画面に公開URLが表示される
   - 形式:`https://<ユーザー名>.github.io/<リポジトリ名>/`

このURLを、PCでもスマホでも開けばアプリが使える。

## ホーム画面に追加する

- **iPhone(Safari)**:共有ボタン → 「ホーム画面に追加」
- **Android(Chrome)**:メニュー(⋮) → 「ホーム画面に追加」
- **PC(Chrome/Edge)**:アドレスバー右のインストールアイコン、またはメニュー → 「アプリとしてインストール」

追加するとアドレスバーのない全画面で開き、アプリのような見た目になる。

## データの保存について

記録はブラウザの保存領域(localStorage)に入る。つまり:

- **端末ごとに別々**。PCの記録とスマホの記録は共有されない
- ブラウザの閲覧データを消すと、記録も消える
- サーバーには何も送られない(完全にローカル)

端末間で同期したい場合は、Supabase や Firebase などのデータベースを組み込む必要がある。

## 設定できるもの

- **Goal line** — 祝福ライン。デフォルトは3分。この時間以内に着手できたら、金色の演出と祝福音が出る
- **Chime & nudges** — 音のオン/オフ

## 音のタイミング

| タイミング | 音 |
|---|---|
| GO! を押した時 | 短い高音 |
| 祝福ライン以内で着手 | 上昇するアルペジオ + 金色の演出 |
| 残り1分 | ピンポーン(2音)、犬がぴょこんと跳ねる |
| 残り1分〜ライン到達 | 3秒間隔で1音ずつ |
| ライン超過 | 2秒間隔に切り替わり、犬がもう一度跳ねる |
